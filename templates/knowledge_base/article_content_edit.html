{% lucide "circle-help" size=18 %} How to Write an Article

Structure your article with headings

Use the Paragraph/Heading dropdown at the left of the toolbar to turn the current line into a Heading 1, 2, or 3 (or back to a plain Paragraph). Headings aren't just visual — they're what builds the structure:

  • Once you add two or more headings, an Outline appears in the sidebar so you can jump between sections while writing.
  • Readers get the same structure as a collapsible table of contents on the published article page.
  • Use Heading 1/2 for major sections (Overview, Steps, Troubleshooting) and Heading 3 for sub-points within a section — keeping a consistent order (don't jump from a Heading 1 straight to a Heading 3) makes the outline and table of contents easiest to follow.

Formatting

Bold, italic, inline code, and code blocks work like any editor. Use the three alignment buttons to left/center/right-align the current paragraph or heading.

Images

Click the image button to upload a file, or just drag-and-drop or paste an image straight into the editor — no need to host it elsewhere and paste a URL.

Tables

The table button inserts a 3×3 starting table with a header row. Click inside a cell to type; press Tab to move to the next cell (Tab from the very last cell automatically adds a new row).

To make a table bigger than 3×3 — or remove a row/column, or delete the whole table — click anywhere inside the table first: a small Table toolbar appears just below the main toolbar with Add Row, Add Column, Delete Row, Delete Column, and Delete Table buttons. It only shows up while your cursor is inside a table.

Note callouts

The callout button inserts a highlighted "Note" box — good for warnings, prerequisites, or anything that should stand out from the main text.

Links

Select some text and click the link button to attach a URL to it. Click it again with no text selected to add/remove a link on your cursor position.

Saving & unsaved changes

Click Save when you're done — this saves a new version you can always revert to later from Version History. Use Edit Details to change the title, category, visibility, or tags without leaving this page. If you try to leave the page with unsaved changes (Cancel, sidebar, browser back/close), you'll get a warning so you don't lose your work by accident.
